- Release: `may2026`
- Version: `2026.5.8.1`
- Size: `966480` bytes
- SHA-256:
  `DCFDEC10244E02CF5037FBA089C55FB7E1326B1C8181742D77D15FA5CB5EEF06`

The texture workflow uses it for BC7 DDS/PNG conversion. The binary is kept in
this fixed local path so builds do not depend on the user's `PATH`.
