# EXVS FHM2D Unpack

EXVS 系列街机资源目录的便携式 FHM2D 纹理解包、立绘映射与预览工具。

工具包内置 Python、Pillow、NumPy 和 DirectXTex Texconv，目标电脑无需单独安装 Python 环境。当前工作流主要面向 `vsac29` 数据集，支持从 FHM2D 中提取已确认的 BC7/RGBA8 纹理，建立人物立绘映射，并在预览器中组合、检查和替换立绘图层。

> 说明：本项目用于资源学习、研究和个人备份流程验证。请勿用于分发版权资源，也不要让工具直接覆盖游戏目录中的原始 FHM2D 文件。

## 快速开始

将整个工具目录放在任意 `vsac*_Release.exe` 的同级目录：

```text
游戏目录/
  vsac*_Release.exe
  data/
  EXVS_Texture_Toolkit/
```

根目录提供两个启动入口：

```text
启动解包工具.bat
启动立绘查看器.bat
```

首次使用建议按这个顺序执行：

1. 运行 `启动解包工具.bat`。
2. 在解包工具中执行“一键建立完整立绘库”。
3. 等待提取、目录生成和人物映射完成。
4. 运行 `启动立绘查看器.bat` 预览和测试立绘组合。

## 主要功能

- 扫描 `data\x64\dplcache_release` 下的 FHM2D 文件。
- 断点续跑提取已确认的 `46XTimg` 纹理。
- 重建 BC7/RGBA8 DDS，并转换为 RGBA PNG。
- 生成全局纹理目录和逐图验证报告。
- 自动识别局外领航员、局内领航员和战斗人员立绘。
- 组合主体、眼睛、嘴部和表情状态图层。
- 上传同尺寸 RGBA PNG，实时查看替换后的组合效果。
- 将替换图保存在 `workspace\asset-mapping\replacements`。
- 为 `vsac29` 提供预建人物映射数据库；版本签名不匹配时才重新分析。

## 纹理格式支持

### BC7

FHM2D 格式码：

```text
0x4E0 -> BC7_UNORM
```

已完成：

- DDS DX10 头重建。
- Texconv 转 RGBA PNG。
- PNG 重新编码为 BC7。
- top mip 替换。
- deflate 数据块和 FHM2D 索引重建。
- 无修改回封字节一致性验证。
- 修改版游戏内加载测试。

全量数据中已提取并验证 25,973 张 BC7 图片。

### RGBA8

FHM2D 格式码：

```text
0x400 -> R8G8B8A8_UNORM
```

全量数据中已提取并验证 14,352 张 RGBA8 图片，已检查：

- PNG 为 RGBA 模式。
- 分辨率与元数据一致。
- 像素数据长度与格式一致。

目前 RGBA8 已完成提取、目录和 PNG 验证，尚未达到 BC7 工作流同等级的修改回封和游戏内替换验证。

### 杂项和 UI 纹理

工具可以提取属于已确认 BC7/RGBA8 格式的 UI、背景和其他杂项纹理，但目前没有为这些资源建立统一的语义分类或组合规则。

以下两个与人物目标尺寸相同但结构歧义的 UI 组已明确排除：

```text
0x0255A27A/g00
0xEF170E82/g00
```

## 当前边界

- “全部纹理”仅指当前已确认的 `46XTimg` BC7/RGBA8 结构。
- 不包含尚未识别的其他纹理容器或 GPU 格式。
- 预览器复现静态图层坐标，不等于复现游戏完整动画状态机。
- 游戏运行时何时选择某个眼睛或嘴部状态，仍由游戏逻辑控制。
- RGBA8 修改回封尚未达到 BC7 工作流的验证程度。
- 不要让程序直接覆盖游戏目录下的原始 FHM2D。
